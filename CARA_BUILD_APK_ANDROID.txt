PANDUAN DEPLOY PWA DI GITHUB PAGES & INSTALL DI ANDROID
====================================================================
Semua file asli untuk PC/Windows (server.ts, JALANKAN_APLIKASI.bat,
JALANKAN_KIOSK.bat, BUILD_DAN_START.bat, data/) TETAP UTUH dan TIDAK
DIUBAH agar penggunaan di laptop/PC tetap berjalan normal.

--------------------------------------------------------------------
CARA DEPLOY PWA OTOMATIS KE GITHUB PAGES (GRATIS & HTTPS PUBLIK)
--------------------------------------------------------------------
Workflow sudah disiapkan di: .github/workflows/deploy-pwa.yml

Langkah-langkah di GitHub:
1. Buat repository baru di GitHub (disarankan Public agar GitHub Pages
   gratis, atau Private jika memakai GitHub Pro/Team).
2. Upload seluruh isi folder project ini ke repository (branch main/master).
3. Di halaman repository GitHub, masuk ke:
   Settings -> Pages -> Build and deployment -> Source: pilih "GitHub Actions".
4. Workflow "Deploy PWA to GitHub Pages" akan berjalan otomatis
   (atau jalankan manual lewat tab Actions -> Run workflow).
5. Setelah selesai (status hijau), akan muncul link HTTPS publik, contoh:
   https://<username>.github.io/<nama-repo>/

--------------------------------------------------------------------
CARA INSTALL DI HP ANDROID (TANPA ERROR)
--------------------------------------------------------------------
1. Buka link GitHub Pages (https://<username>.github.io/<nama-repo>/)
   di Google Chrome HP Android.
2. Ketuk tombol "Install di Android / HP" (atau menu titik tiga Chrome ->
   "Tambahkan ke Layar utama" / "Install aplikasi").
3. Aplikasi akan terpasang dengan ikon ISCS Engine dan berjalan
   100% OFFLINE di HP Android.

--------------------------------------------------------------------
OPSI TAMBAHAN: BUILD .APK LOKAL DI WINDOWS (CAPACITOR)
--------------------------------------------------------------------
Jika suatu saat tetap ingin membuat file .apk lokal di PC Windows yang
terpasang Java JDK & Android Studio, tetap tersedia skrip:
-> BUILD_APK_ANDROID.bat
